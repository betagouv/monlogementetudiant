# Un code de connexion en secours du lien
Le mail de connexion des gestionnaires contient désormais un code à 6 chiffres. Si le filtre de sécurité de la messagerie a ouvert le lien avant vous, la page de connexion vous reconnaît automatiquement dans le navigateur où vous avez fait la demande, ou vous propose de saisir ce code.
