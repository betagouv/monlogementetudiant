# Connexion par code à usage unique pour les gestionnaires
En alternative au lien de connexion, les gestionnaires peuvent recevoir un code à 6 chiffres à saisir directement — utile lorsque les filtres de messagerie d'entreprise font expirer les liens avant leur ouverture.
