# Descriptions de résidence structurées par rubriques
Les gestionnaires renseignent désormais la description de leur résidence en rubriques (accroche, localisation, services, accueil, modalités pratiques). Sur la fiche résidence, chaque rubrique est séparée pour une lecture plus claire.
