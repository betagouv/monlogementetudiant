# Les gestionnaires récupèrent leurs demandes de contact par API
Avec une clé d'API fournie par l'équipe, un bailleur peut récupérer automatiquement les demandes « Être recontacté » de ses résidences dans son propre outil, sans passer par l'espace bailleur.
